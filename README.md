# Thermal-Maps-with-Excel
Calculate and display temperature distribution in 2D thermal models.

- We include 3 files for different security levels.
	- Excel xlsm Macro File
	- Excel xlsx with corresponding *.bas macro file.
- Execution of “Process” macro with calculate all Worksheet ranges whose name start with TABLE.
  - You can hide Sheets that you don’t want to calculate.
- In config File DataColor is defined as a text color. 
	- Values with this color are constant.
- We can define a transmission coefficient using border colors for each cell border.
	- For instance, red border has a 0.02 value assigned, you can modify these values at will.
- After calculation 3D Graphic is created beside the table with its same size.
